Делай строго по порядку, не перепрыгивай. Если что-то непонятно — остановись

Обозначения:

## Что вообще происходит (прочитай один раз)

Мы **не деплоим свои контракты**. Токен выпускает лончпад **Pons**:
- ROBX — обычный ERC-20, фиксированные 1 000 000 000, без налога и без владельца;
- Pons сам создаёт пул Uniswap v3 **ROBX/WETH с комиссией 1%** и лочит ликвидность
  в своём локере;
- из этой 1% комиссии **70% идёт создателю** (это 0.7% от объёма торгов) —
  вот это и есть наша казна.

Казна — это **кошелёк + сервис `keeper/`**. Каждые 30 минут кипер:
забирает комиссию из локера → смотрит, кто держит ROBX → начисляет каждому его долю →
меняет WETH на выбранную акцию → отправляет. Никакого «claim» нет, выплаты
приходят сами, как только накопится больше $1.

## ЧАСТЬ 0. Что приготовить (20 минут)

### 0.1. Кошелёк казны
🦊 Заведи **новый** кошелёк в MetaMask или Rabby (не тот, где личные деньги).
С него будешь запускать токен на Pons, и он же будет payout-кошельком казны.
Сид-фразу запиши на бумагу.

### 0.2. Приватный ключ этого кошелька
MetaMask: три точки → «Данные учётной записи» → «Показать приватный ключ».
Строка вида `0xabc123…`. **Это пароль от денег.** Понадобится ровно один раз —
вставить в Railway (Часть 3).

### 0.3. ETH на Robinhood Chain
Нужен ETH именно **на Robinhood Chain** (chain id 4663), не на Ethereum.
- Переведи ETH через официальный мост: https://docs.robinhood.com/chain/connecting/
- Сколько: **0.05–0.1 ETH** с запасом. Из них:
  - 0.0005 ETH — комиссия запуска на Pons;
  - сколько сам решишь — стартовая ликвидность в пул;
  - ~0.02 ETH — газ киперу на выплаты (каждая выплата это транзакция).

### 0.4. Что подготовить для страницы токена
Название, тикер (ROBX), картинка-логотип (`public/logo-mark.webp` подойдёт),
описание, ссылки на сайт и X (@robinxtech).

## ЧАСТЬ 1. Запуск токена на Pons (15 минут)

### 1.1. Открыть лончпад
🌐 https://www.ponsfamily.com/launchpad — подключи **кошелёк казны** из шага 0.1.
Убедись, что кошелёк на сети Robinhood Chain.

### 1.2. Заполнить и запустить
Название, тикер, картинка, описание, ссылки. Комиссия запуска — 0.0005 ETH.
Если Pons предложит «initial buy» (купить себе часть на старте) — решай сам;
эти токены будут на кошельке казны, и кипер **не** будет платить казне саму
себе (она исключена из снапшота).

### 1.3. ЗАПИСАТЬ АДРЕС ⚠️
После запуска скопируй **адрес токена ROBX** (`0x…`). Он понадобится дважды:
в Railway и в `lib/config.ts`. Запиши его в заметки.

### 1.4. Проверить payout-кошелёк
🌐 Pons отправляет долю создателя на payout-кошелёк. По умолчанию это тот,
с которого запускали. Если в интерфейсе Pons есть поле «fee wallet» /
«payout wallet» — убедись, что там кошелёк казны из шага 0.1, и что это
**тот же кошелёк, чей ключ ты дашь киперу**. Иначе кипер не сможет забирать
комиссию (в логах будет `pons: … may not collect fees`).

### 1.5. Проверить в эксплорере
🌐 https://robinhoodchain.blockscout.com/address/АДРЕС_ROBX — должны быть
видны токен, пул и транзакции.

## ЧАСТЬ 2. Ликвидность и первая покупка (10 минут)

Pons заливает ликвидность сам при запуске и лочит LP в своём локере —
вручную ничего создавать и лочить не надо, это уже сделано.

### 2.1. Контрольная покупка
🦊 Купи немного ROBX со **второго** кошелька (не с казны) через страницу токена
на Pons. Это и проверка, что пул работает, и первая комиссия в казну.

### 2.2. Проверить, что комиссия капает
Через какое-то время объёма Pons покажет накопленные fees на странице токена.
Даже если там ноль — не страшно, кипер сам заберёт, когда появится.

## ЧАСТЬ 3. Кипер на Railway (20 минут)

Кипер — это и есть казна: он собирает комиссию, считает доли и платит.

### 3.1. Залить проект на GitHub
Если ещё не залит:
🖥️
```bash
cd /Users/johnbuz/Desktop/PROJECTS/robinhood
git push origin main
```

### 3.2. Создать сервис
🌐 https://railway.app → **New Project** → **Deploy from GitHub repo** → твой репозиторий.

### 3.3. Указать папку кипера
🌐 Settings → **Root Directory** = `keeper`.
Остальное Railway возьмёт из `keeper/railway.json` (сборка, `npm start`,
healthcheck на `/health`).

### 3.4. ⚠️ Подключить Volume — САМОЕ ВАЖНОЕ
🌐 Settings → **Volumes** → Add → mount path `/data`.

Без него при каждом редеплое стирается леджер — то есть всё, что холдерам
начислено, но ещё не выплачено. Это единственная ошибка, которая реально
стоит людям денег.

### 3.5. Прописать переменные
🌐 Вкладка **Variables**:
| Имя | Значение |
| --- | --- |
| `STATE_DIR` | `/data` |
| `ALLOW_ORIGIN` | адрес сайта, например `https://robinx.tech` |
| `ROBX_TOKEN` | адрес токена из шага 1.3 |
| `TREASURY_PRIVATE_KEY` | приватный ключ кошелька казны (шаг 0.2) |

Пока не заданы `ROBX_TOKEN` и `TREASURY_PRIVATE_KEY` — кипер работает
в **DRY-RUN**: всё считает, ничего не отправляет. Это нормальный способ
посмотреть на него до запуска.

Остальное менять не нужно — акции выплат (TSLA/NVDA/SPCX), локер Pons, RPC,
порог $1 и параметры перпов уже прописаны по умолчанию.

### 3.6. Запустить и проверить
🌐 Вкладка **Logs** — должно быть:
```
RobinX keeper starting…
rpc         rpc.mainnet.chain.robinhood.com
token       0x…
treasury    0x…
holder scan starts at block …
pons: no fees to collect yet          ← нормально, пока нет объёма
marks · TSLA 375.3 · NVDA 227.38 · SPCX 151.85
keeper running · epoch every 30m
```
🌐 Networking → **Generate Domain**, открой `https://твой-домен/status` —
должно быть `"ok": true`, `"chainId": 4663`, `"dryRun": false`.

Держи сервис включённым (тип **Service**, не Cron): он отдаёт `/status`
сайту и обновляет марки для перпов между эпохами.

### 3.7. Закинуть газ
🦊 На кошельке казны должно быть **~0.02 ETH** на Robinhood Chain. Каждая
выплата холдеру — отдельная транзакция. Если газ кончится, в логах будет
`treasury ETH low` и невыплаченное просто перенесётся на следующую эпоху.

## ЧАСТЬ 4. Оживить сайт (10 минут)

### 4.1. Вписать адреса в конфиг
Открой `lib/config.ts`:
- `ROBX_TOKEN_ADDRESS` = `"АДРЕС_ROBX"` → баланс начнёт читаться из кошелька;
- `BUY_ROBX_URL` = ссылка на страницу токена на Pons → заработает кнопка «Buy ROBX».

### 4.2. Указать сайту кипер
🌐 На Vercel → Settings → Environment Variables:
```
NEXT_PUBLIC_KEEPER_URL = https://твой-домен-на-railway
```
Это **главный рубильник**: с ним Treasury показывает живые цифры, а перпы
выходят из режима превью.

### 4.3. Опубликовать
🖥️
```bash
cd /Users/johnbuz/Desktop/PROJECTS/robinhood
npx vercel --prod
```

### 4.4. Проверить руками
🌐 Открой `/terminal`, подключи кошелёк:
- Dashboard — баланс ROBX читается из кошелька;
- Treasury — «In the treasury» и число холдеров не нули, идёт обратный отсчёт;
- выбери акцию (tNVDA) → MetaMask попросит **подписать** (не транзакция, газ
  не тратится) → тост «Payouts set to tNVDA»;
- проверь: `https://кипер/account?owner=ТВОЙ_АДРЕС` → `"choice": "NVDA"`.

## ЧАСТЬ 5. Первые часы после запуска

- **Первая эпоха** может не выплатить ничего — это нормально: пока объём мал,
  ни у кого не накопился $1. Начисления при этом идут всем, они в леджере.
- **Перпы** сначала не дадут открыть позицию: резерв дома копится из 10%
  комиссии каждой эпохи. Пока резерв $0, максимальный размер позиции $0.
  Так и задумано — выигрыш не должен платиться из чужих начислений.
- **Крупный холдер** в логах: `0x… holds 42.3% and is NOT excluded` — если это
  биржа или чей-то vault, добавь адрес в `EXCLUDE_ACCOUNTS` на Railway.
- **Смотри `/status`** — `pendingFeeUsd` (сколько комиссии пришло),
  `ledger.paidOutUsd` (сколько уже выплачено), `epochsRun`.
